# Judging Score Optimization Guide

- **UI/UX (15)**: consistent design system, professional palette, generous whitespace, micro-interactions, mobile polish
- **Functional (25)**: run the requirements matrix weekly; no requirement left red
- **Admin (15)**: make CRUD fast and obvious; visible success feedback; publish/unpublish visible
- **RAG (15)**: rehearse supported/unsupported/error; show grounding behavior confidently
- **Code/architecture (10)**: clean folders, typed contracts, reusable components, can explain every piece
- **Perf/SEO/a11y (8)**: optimize images, write real titles/metas, pass keyboard walkthrough
- **Security/SMTP (7)**: protect admin, show 401 on unauth API call, demo SMTP email arriving
- **Docs/deploy/presentation (5)**: README, live URL, crisp demo flow

Priority when time is short: requirements coverage (25) > RAG (15) > admin (15) > UI/UX (15) > security/SMTP (7) > perf/SEO (8) > docs (5).
