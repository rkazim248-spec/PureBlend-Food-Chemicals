# Jury Demo Flow

1. Homepage — explain design direction and trust positioning
2. Responsive resize — show breakpoints live
3. Product browsing — `/products`, loading → grid
4. Product detail — `/products/[slug]`, SEO-friendly
5. Admin login — `/admin/login`
6. Add/edit a product — show form, save, success toast
7. Public site reflects change — refresh product page
8. Banner management — add/reorder banner, homepage carousel updates
9. Offer management — add offer, `/offers` shows it
10. FAQ management — add FAQ, `/faqs` shows it
11. SEO controls — edit meta title, view page source
12. AI RAG chatbot — open widget
13. Supported question — grounded answer
14. Unsupported question — refusal behavior
15. Contact form — submit, show success + email received
16. Final responsive demonstration — mobile viewport walkthrough

Do NOT fake any step. If a step fails, narrate the error state — it demonstrates understanding.
