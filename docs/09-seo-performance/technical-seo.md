# Technical SEO Checklist

- [ ] Titles/descriptions from SEO settings (public pages)
- [ ] Semantic HTML, heading order
- [ ] Alt attributes on images
- [ ] OG title/description/image
- [ ] Canonical URLs
- [ ] robots.txt allows public pages, disallows /admin
- [ ] sitemap.xml includes public routes
- [ ] 404 returns proper status and noindex
- [ ] No broken internal links
- [ ] Mobile-friendly rendering
