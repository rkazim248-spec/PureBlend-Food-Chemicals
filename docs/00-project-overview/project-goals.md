# Project Goals

## Primary Goal
Deliver a production-minded, fully functional solution for PureBlend Food Chemicals that satisfies every organizer requirement and scores competitively across all 100 evaluation marks.

## Product Goals
1. Give visitors a trustworthy, professional view of PureBlend products, offers, and FAQs.
2. Let PureBlend staff manage all site content without developer involvement.
3. Provide an AI chatbot that answers only from approved knowledge and clearly refuses otherwise.
4. Convert visitor interest into inquiries via a working SMTP contact flow.

## Technical Goals
1. Clean, layered architecture (public site, admin, API, database, RAG service).
2. One approved API contract shared by frontend and backend.
3. Secure-by-default: backend is the final authorization boundary.
4. Responsive, accessible, SEO-optimized public site.
5. Reproducible deployment with documented environment variables.

## Process Goals
1. Documentation complete before implementation (this phase).
2. Traceability: every requirement → acceptance criteria → test case → demo step.
3. AI coding tools follow `/docs/11-development/ai-coding-rules.md`.

## Non-Goals (see also out-of-scope)
- Building a real e-commerce checkout (unless the organizer statement requires it — verify).
- Multi-language support (TEAM DECISION / TO BE DECIDED).
- Customer accounts for public users.
