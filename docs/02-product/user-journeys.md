# User Journeys

## Journey 1 — Buyer discovers a product
1. Lands on homepage → sees hero banner and featured products
2. Navigates to /products → browses catalog
3. Opens /products/[slug] → reads specs
4. Opens chatbot → asks about availability → grounded answer or honest refusal
5. Goes to /contact → submits inquiry → confirmation

## Journey 2 — Admin updates content
1. Logs in at /admin/login
2. Opens Products → Edit → changes description → Save
3. Sees success toast
4. Visits public product page → change visible

## Journey 3 — Visitor handles edge cases
1. API fails → sees error state with retry
2. List is empty → sees meaningful empty state
3. Bad URL → custom 404
