## Brand & Style

This design system establishes a high-trust, scientific, and enterprise-grade aesthetic for high-purity food-grade chemicals and ingredient manufacturing. The visual direction balances institutional authority with modern bio-chemical clarity.

### Personality & Audience
- **Target Audience:** Procurement directors, food scientists, regulatory compliance officers, and global supply chain managers.
- **Brand Attributes:** Verifiable purity, uncompromising compliance, precision formulation, and ecological stewardship.
- **Emotional Response:** Institutional trust, absolute safety, crisp laboratory efficiency, and premium B2B reliability.

### Design Movement
- **Modern Technical / Bio-Scientific Precision:** Combines structured data density with organic botanical undertones. Clean, expansive negative space (minimum 60% neutral canvas) prevents dense chemical data sheets and lot-tracking tables from feeling overwhelming. Surfaces are defined by soft sage tints, crisp boundaries, and subdued forest tones rather than harsh tech-skeuomorphism.

## Colors

The palette references deep botanical chlorophyl and clean room environments, structured to support rigorous compliance workflows.

### Palette Architecture
- **Primary Brand (`#12372A` - Deep Forest Green):** Used for authoritative structural anchors: primary action buttons, active navigation states, high-level headers, and core brand accents.
- **Secondary Brand (`#1F7A5A` - Emerald Green):** Used for interactive affordances, active hover/focus states, secondary text actions, and interactive pill badges.
- **Tertiary / Accent (`#C9A227` - Warm Gold):** Reserved strictly for high-value signifiers: Certificate of Analysis (CoA) verified seals, ISO/FSMA compliance stamps, lot purity tiers, and top-tier SLA badges.
- **Dark Brand (`#0D211A` - Night Forest):** Anchors grounding elements including global footers, deep contrast marketing bands, and enterprise AI assistant modules.
- **Surfaces & Tonal Backdrops:**
  - Canvas Background: Pale Clean Neutral (`#F8FAF7`)
  - Elevated Container / Surface: Crisp White (`#FFFFFF`)
  - Soft Brand Tint: Soft Sage (`#EAF3EE`) for category pills, active filter chips, table row hover overlays, and highlight containers.
- **Content Hierarchy:**
  - Text Primary: `#17211D` (Formulas, chemical nomenclature, titles)
  - Text Secondary: `#52615A` (CAS numbers, table headers, descriptions)
  - Text Muted: `#7A8781` (Disclaimers, inactive metadata)
- **Structural Lines:**
  - Base Border: `#D8E2DC` (1px clean architectural boundaries)
- **System States:**
  - Success: `#16845B` (Compliant, Passed CoA, In Stock)
  - Warning: `#B7791F` (Pending Audit, Shelf-Life Nearing)
  - Error: `#C83E3E` (Failed Spec, Out of Stock, Recalled)
  - Info: `#287A8A` (Documentation Note, Revision Available)

## Typography

The typographic balance relies on Manrope for confident, modern geometric display hierarchy, complemented by Inter for high-density, accessible tabular and specification data.

### Hierarchy & Style Rules
- **Headings (Manrope):** Set with tight tracking to project authority and precision. Weights are kept strictly to 600 (SemiBold) and 700 (Bold) to maintain structural cadence.
- **Interface & Data (Inter):** Uses tabular figures (`font-variant-numeric: tabular-nums`) across all product catalogs, chemical assays, concentrations, batch metrics, and inventory data to ensure absolute column alignment.
- **Chemical Formulae & CAS Identifiers:** Rendered using `code-sm` or `label-md` with strict baseline alignment to preserve molecular sub/superscripts without breaking paragraph line-heights.

## Layout & Spacing

A disciplined 8-point baseline rhythm anchors all margins, paddings, and column geometries, providing clinical order across complex enterprise screens.

### Grid Structure
- **Desktop (1200px+):** 12-column fluid grid within a 1440px max-width container. `margin-lg` (80px / 5rem) canvas framing with `gutter-lg` (32px / 2rem) column separations.
- **Tablet (768px - 1199px):** 8-column layout with `margin` (32px / 2rem) and `gutter` (24px / 1.5rem).
- **Mobile (< 768px):** 4-column layout with `margin-sm` (16px / 1rem) and `gutter-sm` (16px / 1rem).

### Layout Philosophy
- **Density Management:** Maintain a minimum 60% negative space on informational landing sections. In high-density workflow screens (e.g., Lot Search, Certificate Repository, Batch Reordering), leverage `space-xs` (4px) and `space-sm` (8px) within cells, pairing with generous external card margins (`space-xl` / 32px) to prevent cognitive fatigue.

## Elevation & Depth

Visual hierarchy is maintained through crisp surface planes and organic ambient diffusion tinted with deep forest tones rather than flat synthetic grays.

### Elevation Levels
- **Level 0 (Flat Canvas):** `#F8FAF7`. Structural containers and table headers directly anchor to the canvas via `#D8E2DC` 1px border rules.
- **Level 1 (Card & Content Surface):** `#FFFFFF` fill with `border: 1px solid #D8E2DC` and subtle ambient lift:
  `box-shadow: 0 4px 20px -2px rgba(18, 55, 42, 0.06);`
- **Level 2 (Hover & Active Interactive State):** Activated catalog tiles and active filter sheets:
  `box-shadow: 0 8px 28px -4px rgba(18, 55, 42, 0.10);`
- **Level 3 (Flyouts, Menus & Dropdowns):**
  `box-shadow: 0 12px 32px -4px rgba(18, 55, 42, 0.14);`
- **Level 4 (Modals & Certificate Viewers):**
  `box-shadow: 0 24px 48px -12px rgba(13, 33, 26, 0.22);` paired with a backdrop blur overlay (`backdrop-filter: blur(4px); background: rgba(13, 33, 26, 0.5)`).

### Outline & Border Paradigm
All elevated surfaces retain a distinct `1px solid #D8E2DC` boundary line to preserve laboratory-grade visual containment under fluctuating display calibrations.

## Shapes

The design system uses a balanced curvature hierarchy that merges modern software softness with scientific discipline.

### Corner Radius Mapping
- **Base Components (`rounded`: 0.5rem / 8px):** Input fields, standard dropdown triggers, table selection targets, and contextual menus.
- **Primary Cards & Modules (`rounded-lg`: 1rem / 16px):** Product specification cards, safety data panels, certification modules, and dialog overlays.
- **Badges, Tags, & Status Pills (`rounded-full`: 9999px):** All chemical purity metrics, compliance flags, lot status markers, and interactive filter chips.

## Components

### Buttons
- **Primary:** Background `#12372A`, text `#FFFFFF`, border none, radius `8px` (`0.5rem`). Hover: `#1F7A5A`. Focus: 2px offset ring with `#1F7A5A`.
- **Secondary:** Background `#EAF3EE`, text `#12372A`, border `1px solid transparent`. Hover: background `#D8E2DC`.
- **Outline:** Background transparent, text `#12372A`, border `1px solid #D8E2DC`. Hover: background `#FFFFFF`, border `#12372A`.
- **Destructive:** Background `#C83E3E`, text `#FFFFFF`. Hover: `#A82F2F`.
- **Sizing:** Compact (36px height, `space-sm` inline), Default (44px height, `space-md` inline), Large (52px height, `space-lg` inline).

### Input Fields & Selects
- **Base Input:** Background `#FFFFFF`, border `1px solid #D8E2DC`, radius `8px`, height 44px, text `#17211D`, placeholder `#7A8781`.
- **Focus State:** Border `#1F7A5A`, shadow `0 0 0 3px rgba(31, 122, 90, 0.15)`.
- **Labeling:** Positioned above input using `label-md` in `#52615A`. Supporting and helper text uses `body-sm` in `#7A8781`.

### Chips & Badges
- **Specification / Status Chips:** Pill-shaped (`rounded-full`), height 24px, padding `2px 10px`, typography `label-sm`.
  - *Certified / Passed:* `#EAF3EE` background, `#16845B` text, `1px solid rgba(22, 132, 91, 0.2)` border.
  - *Warm Gold Compliance Stamp:* Tinted `#FAF4E1` background, `#C9A227` text, `1px solid #E6D28C` border.
  - *Pending / Audit:* `#FBF4E8` background, `#B7791F` text.
- **Filter Chips:** Height 32px, radius `9999px`, background `#FFFFFF`, border `1px solid #D8E2DC`. When selected: background `#EAF3EE`, text `#12372A`, border `#1F7A5A`.

### Cards & Panels
- **Product & Assay Cards:** Surface `#FFFFFF`, radius `16px` (`rounded-lg`), border `1px solid #D8E2DC`, padding `space-lg`. Hover transitions to Level 2 elevation and border color `#1F7A5A`.
- **CoA / Quality Certificate Cards:** Features a subtle `2px` left accent border using `#C9A227` (Warm Gold) to signify official verification.

### Tables (Lot & Chemical Catalogs)
- **Header:** Background `#F8FAF7`, typography `label-sm` in uppercase tracking (`letterSpacing: 0.04em`), color `#52615A`, border-bottom `1px solid #D8E2DC`.
- **Row:** Height 52px, zebra striping avoided in favor of crisp `1px solid #D8E2DC` dividers. Hover state shifts row surface to `#EAF3EE`.
- **Data Cells:** Typography `body-md` with tabular numerals enabled.

### Checkboxes & Radios
- **Checkbox:** 18x18px, radius `4px`, border `1.5px solid #7A8781`. Checked state: background `#12372A`, border `#12372A`, white check icon.
- **Radio:** 18x18px, circular, border `1.5px solid #7A8781`. Checked state: border `#12372A`, inner dot `#12372A`.

### Iconography Rules
- Clean line iconography with uniform `1.75px` stroke weight. Icons align to a 20x20px or 24x24px grid with stroke caps and corners set to rounded. Icon color defaults to `#52615A`, switching to `#12372A` or `#1F7A5A` on interactive states.
