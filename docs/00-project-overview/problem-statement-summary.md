## Summary of the Client Problem (per organizer brief)
PureBlend Food Chemicals (fictional) needs a complete, production-minded web solution — not a visual prototype — covering:

- Modern responsive public website
- Database-driven products
- Secure admin dashboard
- Dynamic content management
- Banner/carousel management
- Product CRUD
- Offers/discount management
- FAQ management
- SEO controls
- AI RAG chatbot restricted to approved PureBlend knowledge
- SMTP contact workflow
- Authentication and authorization
- Security controls
- Performance
- Accessibility
- SEO
- Deployment
- Documentation

## Explicit Organizer Rules
- Placeholder/fake hard-coded admin controls do **not** count as complete functionality.
- The chatbot must be restricted to approved PureBlend knowledge and must not act as a general-purpose assistant.
- Contact workflow must use SMTP with anti-spam protection.
- Every feature must be functional, not mocked.
